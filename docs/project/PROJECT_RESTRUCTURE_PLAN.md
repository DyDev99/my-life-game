# Project Restructure Plan — ជីវិតខ្ញុំ (My Life)

**Phase 2 — Design.** This plan needs review. **Nothing below has been executed.**
Read with [PROJECT_STRUCTURE_REPORT.md](PROJECT_STRUCTURE_REPORT.md).

## Guiding decisions

1. **Adapt, don't transplant.** This is a Next.js 16 + React Three Fiber game, so Unity concepts map like this:
   - `Assets/_Project/*` → `src/`
   - `Scenes`/`Prefabs` → React components
   - `Art/Blender` → `art-source/`, outside anything served or bundled
   - runtime art → `public/`, which Next.js serves as-is
2. **Only create folders that will hold files now.** No empty `Weapons/`, `Enemies/`, `Networking/`, or `Tests/Performance/`.
3. **Feature folders inside `src/game/`.** Each feature keeps its components, logic, and (later) tests together.
4. **`public/` URLs stay unchanged in the first pass.** They are untyped runtime strings, so a central registry comes first and any rename comes later and optionally.
5. **Pure moves and refactors go in separate commits.** A "move" commit only changes paths and imports, so `git diff -M` shows 100% renames.
6. **Keep the `useGameStore` public API stable** while splitting it into slices, so the 28 consumer files don't need changes.
